# VII. ACADEMIC ASSESSMENTS AND PROCTORING

## ACCELERATION DOES NOT REDUCE ACADEMIC REQUIREMENTS.

| Academic Component | Requirement |
|---|---|
| Objective Assessment (OA) | 25 questions per assessment. |
| Performance Assessment (PA) | One task-based assessment. |
| Combined Assessment | OA and PA required when assigned. |
| Passing Score | **80% or higher on each required academic assessment.** |
| Proctoring | **ProctorU for required objective and performance assessments.** |
| Regular Course Assessment | Applicable **proctored OA, PA, or both**. |
| Capstone Course Assessments | **Both objective and performance assessments are required and proctored through ProctorU.** |
| Cumulative Capstone Project | **Not proctored and not a separate examination.** Developed, reviewed, and evaluated under a project rubric. |
| Project Rubric | Defines the project's required components, milestones, deliverables, and quality expectations. Students must meet **a minimum of 80%** on the applicable project rubric. |
| Project Launch and Continuity | The student begins the assigned project in the first applicable course and develops and expands that same cumulative project through subsequent courses in Bachelor's Year 4, Master's, or MBA coursework, as applicable. |
| Project Supervision | An assigned industry-professional supervisor guides progress, answers student questions, reviews rubric expectations, provides feedback, and monitors required milestones. **Supervision is not proctoring.** |
| Capstone Course Deliverables | Completed cumulative project, PowerPoint presentation, written paper, required objective and performance assessments, and virtual human panel review. |
| Virtual Human Panel | The student presents and responds to questions before a panel representing **peers, employers, the assigned supervisor, faculty, and experiential staff**. |
| Certification Review | Required for applicable certification-track students. |
| Professional Supervision | Required for designated courses and capstones. |
| Course Progression | Complete prerequisites, applicable OA/PA assessments, and supervised rubric-based project milestones. |
| Course Unlocking | Subject to academic progression and applicable payment requirements. |
| Accelerated Students | Same assessments, project rubric standards, supervision, capstone deliverables, and completion requirements. |

### Assessment Structure

| Assessment Type / Component | Proctored | Passing / Completion Requirement |
|---|---|---|
| Regular-Course Objective Assessment | Yes — ProctorU when assigned | 80% or higher. |
| Regular-Course Performance Assessment | Yes — ProctorU when assigned | 80% or higher. |
| Regular-Course Combined OA + PA | Yes — ProctorU | 80% or higher **on each** required assessment. |
| Ongoing Cumulative Project and Rubric | **No** | Develop the project from its initial course through the applicable subsequent courses; meet the published rubric's components, milestones, and deliverables with **at least 80%**; receive supervisor feedback and guidance. **This is supervised project work, not an examination.** |
| Project Supervision and Student Questions | **No** | Assigned supervisor is available for project questions, ongoing feedback, progress checks, and rubric-based review. |
| Capstone-Course Objective Assessment | **Yes — ProctorU** | 80% or higher. |
| Capstone-Course Performance Assessment | **Yes — ProctorU** | 80% or higher. |
| Capstone Project Submission | **No** | Submit the actual cumulative project developed throughout the applicable coursework, a written paper, and a PowerPoint presentation; satisfy the applicable project rubric at **80% or higher**. |
| Virtual Human Panel Review | **No — live virtual review, not ProctorU proctoring** | Present the cumulative project, explain the paper and presentation, and answer panel questions from peers, employers, the supervisor, faculty, and experiential staff. |
| Capstone Course Completion | Proctored OA and PA; supervised, unproctored project and virtual panel | Complete **both** proctored assessments, the cumulative project and its rubric, the written paper, PowerPoint presentation, and human panel review. |
| Professional Supervision | Not an examination | Required documented supervision and rubric-based project support. |
