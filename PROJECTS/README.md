## Project workflow

**Backlog → Ready → In Progress → In Review → Done**

- **Backlog:** Not yet scheduled or fully prepared for execution.
- **Ready:** Source materials and acceptance criteria exist; eligible to begin.
- **In Progress:** Source work is demonstrably being revised; build/review work is ongoing.
- **In Review:** A draft exists and awaits verification, approval, or handoff.
- **Done:** Scoped work has verified completion; these two closed issues represent documentation only, not a launched site.
